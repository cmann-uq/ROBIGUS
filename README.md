# ROBIGUS

Reproducible Object-Based Image-Guided Uredinia Scoring

Short description:
“ROBIGUS is an ImageJ/Fiji macro package for semi-automated quantification of wheat rust disease from digital images.”

Requirements — Fiji/ImageJ
Files — Calibration macro, Quantification macro, example data, guide
Quick start — calibrate → save profile → quantify
